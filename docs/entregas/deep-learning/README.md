## Contenido mínimo de la presentación

- [ ] Problema, contexto, relevancia, objetivo general y específicos
- [ ] Arquitectura: modelo, funcionamiento, referencia de la literatura y
      **modificaciones** respecto al original; por qué es apropiada
- [ ] Datos: procedencia, características, split train/valid/test, normalización,
      aumento de datos; cada decisión justificada
- [ ] Entrenamiento: curvas de loss y métricas (train y valid), hiperparámetros
      justificados, pérdida, optimizador, estrategia, recursos (Apolo III, H100),
      análisis de sobreajuste / subajuste / convergencia
- [ ] Resultados: métricas, visualizaciones, **muestras externas** no usadas en
      entrenamiento, fortalezas, limitaciones y fallas
- [ ] Conclusiones ligadas a los objetivos y respaldadas por resultados

## Informe (≤ 3 páginas)

- [ ] Objetivos (problema, general, específicos)
- [ ] Base de datos (origen, características, preprocesamiento, distribución por split)
- [ ] Modelo (arquitectura, justificación, decisiones de implementación y entrenamiento)
- [ ] Resultados (métricas, visualizaciones, evaluación en datos no vistos)
- [ ] Conclusiones (hallazgos, cumplimiento de objetivos, limitaciones)

Todos los integrantes participan en la exposición y deben poder responder sobre
cualquier componente.
